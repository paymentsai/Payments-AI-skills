# Payments AI for Claude Code

Install from the repository marketplace:

```text
/plugin marketplace add paymentsai/Payments-AI-skills
/plugin install payments-ai@payments-ai
```

On the first MCP tool call Claude Code opens a browser or prints a sign-in URL for [Payments AI](https://payments.ai/); run `/mcp` → Authenticate to start it.

Then run `/payments-quickstart` or ask: *help me get started with Payments AI*.
