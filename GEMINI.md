# Payments AI

Use `payments-quickstart` for a merchant account and a first catalogue plan. Use `order-checkout` when the buyer pays for several items in one checkout, the caller sets the price, or the buyer pays on the order's hosted checkout link. Use `checkout-customization` to brand hosted checkout. They call the bundled Payments AI MCP server (`payments-ai`).

On first MCP tool call, complete the OAuth browser flow. If tools are missing, reload Gemini CLI after `gemini extensions install`.
